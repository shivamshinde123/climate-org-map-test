How to add and edit organizations Rules, CSV columns and an example
  • Your changes are live right away. Saving, adding, uploading a CSV or deleting here changes the public map immediately. Organizations sent from the public "Add your organization" page wait under Waiting for review until you approve them, and visitors can never mark them Verified.
  • Required: organization name, town/city, and state. In the form, pick the state from the list; in a CSV, use the two-letter code (MA) or the full name (Massachusetts). Everything else is optional.
  • One organization = name + state. Uploading a CSV row with the same name and state as an existing organization you added updates it. Adding one by hand with a name and state that already exist is refused; edit the existing one instead.
  • Website: example.org is fine; https:// is added automatically.
  • Suggestions: as you type a street address, matching addresses appear; picking one fills in the town, state and ZIP and places the pin exactly. Town/City also suggests towns in the chosen state. Both are only suggestions: you can type any address or town. Address suggestions come from Photon (OpenStreetMap), so what you type in the street address box is sent to that service.
  • Map pin: placed at the street address. If the address is not found, the pin goes to the center of the ZIP code (approximate). With neither, the organization is saved but not shown on the map until you open Edit and enter latitude and longitude (right-click the spot in Google Maps to copy them).
  • Filter columns must use one of the values listed below. Capitalization does not matter; leave a cell blank for "Unknown".
  • Verification: "Verified" or "Not Verified" (default). Marking an organization Verified records today's date as its verification.
  • Survey responses: answers to the verification survey (the map's "Claim and verify this listing" link) arrive under Survey responses. An organization's response waits there: Review & verify opens the editor with its listing (or a new one) filled in from the answers and set to Verified; Save puts it on the map. Municipal and individual responses are research only. Download all responses gives every answer as a CSV with the same columns as the old Google Sheet.
  • Delete: organizations added through the forms or a CSV are deleted permanently. Organizations from the original map data are hidden instead, and can be restored by searching for them, opening Edit and clicking Save.
  • CSV files: the first row must be the column names below (the same as the template). Column order does not matter and other columns are ignored. Save the file as CSV (in Excel: File → Save As → CSV UTF-8).
