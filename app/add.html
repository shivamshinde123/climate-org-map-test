How to add an organization Rules, CSV columns and an example
  • What belongs on the map: community-focused climate and sustainability organizations, such as nonprofits, grassroots groups, coalitions and town committees.
  • Every submission is reviewed. It appears on the map once the Green Community Catalysts team approves it.
  • Required: organization name, town/city, and state. In the form, pick the state from the list; in a CSV, use the two-letter code (MA) or the full name (Massachusetts). Everything else is optional, but a website and street address help us review it faster.
  • One organization = name + state. If an organization with the same name and state has already been submitted, it is not accepted again.
  • Website: example.org is fine; https:// is added automatically.
  • Suggestions: as you type a street address, matching addresses appear; picking one fills in the town, state and ZIP and places the pin exactly. Town/City also suggests towns in the chosen state. Both are only suggestions: you can type any address or town. Address suggestions come from Photon (OpenStreetMap), so what you type in the street address box is sent to that service.
  • Map pin: placed at the street address. If the address is not found, the pin goes to the center of the ZIP code. If neither works, the organization is still submitted and our team places it during review.
  • Filters (type, audience, resilience and so on): pick the closest option, or "Unknown" if you are not sure. In a CSV, use the values listed below; capitalization does not matter, and a blank cell means "Unknown".
  • Verification is done by our team, not on this page. To get an organization marked Verified, open it on the map and use Claim and verify this listing.
  • CSV files: up to 200 organizations per file. The first row must be the column names below (the same as the template). Column order does not matter and other columns are ignored. Save the file as CSV (in Excel: File → Save As → CSV UTF-8).
